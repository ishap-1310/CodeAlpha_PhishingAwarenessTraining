# Phishing Awareness Training GUI

This project is developed as part of the CodeAlpha Cybersecurity Internship.

## 📌 Project Title:
Phishing Awareness Training Module

## 📖 Description:
This is a GUI-based training application developed using Python Tkinter to educate users about phishing attacks, social engineering tactics, and cybersecurity best practices.

## 🚀 Features:
- Introduction to Phishing Attacks
- Identifying Phishing Emails
- Detecting Fake Websites
- Social Engineering Awareness
- Best Security Practices
- Real-world Phishing Examples
- Interactive Quiz with Score

## 🛠️ Technologies Used:
- Python
- Tkinter (GUI)

## ▶️ How to Run:
```bash
python phishing_training.py
